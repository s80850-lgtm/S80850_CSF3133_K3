About the Event

Programming Workshop 2026 is a one-day event designed to help students improve their programming skills and learn from experienced speakers.

Speaker 1: Introduction to Web Development

Dr. Ahmad will teach students the basics of HTML and how to create a simple webpage.

Activity 2: Coding Challenge

Students will work individually to solve programming problems and improve their problem-solving skills.
